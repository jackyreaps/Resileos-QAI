Titanos, Engine

The figurehead

Titanos is the engine over the deterministic residual core. Zeus routing stands over that core. Writes apply only after reviewers approve. The core is the source of truth for exact store, derivation, and abstention.

ACCEPTED

A stored fact

learn Zeus domain sky then query returns ACCEPTED · sky (mode CLASSICAL).

ABSTAINED

An unknown

Unknown pairs return ABSTAINED, value empty. Missing entities and relations stayed empty in the measured probes.

CONFLICT

Dated facts that disagree

When two facts with explicit, overlapping date ranges disagree on the same date, ask() returns CONFLICT instead of picking one.

FAQ

What does Resileos do?

It remembers exact facts you teach it, derives from those facts, and abstains when it does not know. Capability grows as your hubs fill. It does not make things up.

Can it answer as of a date?

Yes. Facts can carry a valid-from and valid-to window. Asking Athens capital_of as of 1800 returned Ottoman. Today returned Greece. When overlapping dated facts disagree, the answer is CONFLICT.

Does it generate images or video from a prompt?

No. The residual engine compresses images and video frames you already have, with measured round-trip error. Generating new pictures from a prompt is in research, not shipped. A Forge draft with no configured provider is UNAVAILABLE, and no URL is invented.

Do I need Docker to try it?

No. Open /chat. Signed-out use is a short per-network daily trial. Choose a username before a thread is saved. Docker is for developers self-hosting.

How do free keys work?

Sign in, then create one free key from Account. The key stays on the server. Developers can reveal it once after an email confirmation. scripts/issue_free_key.py still prints a key for a self-hosted file.

Try it on a username

Chat needs a username before a thread is saved. Sign in from Account to use your own monthly quota.
