Pricing questions

Do I need Docker to try it?

No. Open /chat. The shared demo key is filled in and rate-limited, about 100 usernames. Choose a username before a thread is saved.

How do free keys work?

This page’s form calls the billing free-key API and shows the key once. You can also run scripts/issue_free_key.py and put the hash in the API key file.

What is Founding Builder?

$19/mo, locked for 12 months, capped at 50. Same Builder seat shape: 3 keys and 100,000 requests a month. It does not auto-renew at the founding rate.
