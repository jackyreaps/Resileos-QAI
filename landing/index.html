Built for work that cannot invent

Use it wherever a wrong fluent answer costs more than a blank: knowledge bases, compliance, multi-hop facts, agent memory, and any pipeline where the system of record must stay honest while a language model handles language.

FACTS

Stored triples

Subject–relation–object, verifier-gated on ingest. A fact is either in the store or it is not. No soft match. No “approximately correct.”

DERIVATIONS

Composition with provenance

Chain known relations. Every hop is traceable. Novel combinations of known facts are computed from the algebra, not sampled from training data.

ABSTENTION

Unknown stays unknown

If it is not stored and cannot be derived, the API returns empty or ABSTAINED. It does not fill the gap with a fluent guess.

SCALE

CPU economics

The classical core runs on a small VPS. You pay for structure and queries, not for every token of a model that still cannot guarantee exact recall.
