# Layered Mask Stack

A mask is a binary selection over optional feature bits. At small scale, masks
partition a landscape into basins. At large scale, with layered masks, the
partition boundary saturates: the boundary ceases to be a curve and becomes a
membrane. The regime change is the mask-to-sheath transition.

This document defines the mask stack as a constructive structure — something
the build produces, not something a diagnostic observes. It defines the layers,
the transition criterion, and the API. It does not define the basin metrics used
to observe the transition. Those are RES-304.

## 1. What a mask is

A mask is a `k`-bit selection over a fixed feature set. For the substrate, the
feature set is the oscillator band set from RES-306:

| Bit | Feature | Meaning when set |
|-----|---------|------------------|
| 0 | `csi` | Include causal-sandbox index in the packet |
| 1 | `order_parameter` | Include oscillator order parameter |
| 2 | `direction` | Include directional trend |
| 3..k-1 | reserved | Future features |

A mask is `tuple[bool]` of length `k`. The full stack is a sequence of masks,
ordered by depth. Layer 0 is the finest mask (most bits set); layer `K-1` is the
coarsest.

## 2. Why layers

At small `n`, a single mask is sufficient: the constraint boundary is a curve,
and a binary partition of feature space captures it. At large `n`, a single
mask is insufficient because the boundary's dimension grows with `n`. A stack
of masks, each coarser than the last, provides a multi-resolution partition:
the finest layer resolves local structure, the coarsest layer resolves global
structure.

The stack is the layered-mask answer to the size problem. The sheath is what
happens when the coarsest layer's boundary saturates and the multi-resolution
structure collapses into a single membrane.

## 3. Layer definition

A layer `l` is:

    Layer = {
        mask: tuple[bool],          # length k; metadata only
        carrier: complex128[d],     # prime-tower positional carrier
        weight: float,              # contribution to the stack bundle
        tower_level: int,           # tower level n used to build the carrier
        prime: int,                 # prime p_n used as the carrier frequency
        branch: str,                # 'even' or 'odd'
    }

The **carrier** is a prime-tower positional carrier, not a bundle of band
carriers from the mask bits. It is generated by:

    layer_carrier(layer_index, n_layers, dim, local_first=True)

which maps the layer's position to a tower level `n` (starting at `n = 2`),
takes the `n`-th prime `p_n`, and builds:

    phase[d] = 2π · p_n · d / dim       for d = 0 .. dim-1
    carrier[d] = exp(i · phase[d]) / sqrt(dim)

Adjacent layers differ by a prime gap, not by a constant log step. The carriers
are near-orthogonal by construction (Dirichlet kernel ~1/dim at dim ≥ 256), so
no explicit orthogonality check is needed. The Nyquist bound `2 · p_n < dim`
is enforced at construction time.

The **mask** is metadata. It records which feature bits the layer selects. It
does not influence the carrier. Two stacks with the same config but different
masks produce the same carriers.

The **weight** is the layer's contribution to the stacked hypervector. The
default is `1.0 / (layer_index + 1)`, so finer layers dominate and coarser
layers provide context.

The stack bundle is:

    stack_hv = normalize(Σ_l weight_l · bind(stream_hv, carrier_l))

where `bind` is the codex's exact bind: `a * b * sqrt(dim)`.

## 4. Transition criterion

The mask-to-sheath transition is detected by RES-304's `sheath_metrics`. The
operational criterion is:

    is_sheath = (boundary_codim < codim_max) AND (depth < depth_min)

When `is_sheath` first becomes true, the stack has entered the sheath regime.
At that point, the coarsest layer's boundary fills the state space and the
multi-resolution structure provides no further discrimination.

The stack exposes this as a static method:

    MaskStack.is_saturated(boundary_codim, depth,
                           codim_max=0.5, depth_min=0.05) -> bool

The caller supplies the RES-304 measurement; the stack does not compute it.

## 5. Construction API

    stack = MaskStack(MaskStackConfig(dim=512, k=4, n_layers=3))
    stack.add_layer(mask=(True, True, True, False))
    stack.add_layer(mask=(True, True, False, False))
    stack.add_layer(mask=(True, False, False, False))
    hv = stack.encode(stream_hv)

`add_layer` validates:

- the mask is a tuple of `bool` of length `k`;
- the mask sets at least one bit;
- the stack is not full (`len(layers) < n_layers`).

`add_layer` does **not** validate near-orthogonality between layers, and does
**not** reject duplicate masks. Duplicate masks are meaningful: they select the
same feature bits at two different tower levels. The carriers differ because
the tower levels differ.

`MaskStackConfig` validates at construction time that `n_layers` does not
exceed the tower's usable level count at the given `dim`, i.e. the largest
`n` with `2 · p_n < dim`. At `dim = 16`, Nyquist is 8, the largest usable
prime is 7 (`p_4`), and usable levels are 2..4, so `n_layers ≤ 3`.

`encode` returns the stack bundle. It is a pure function of `stream_hv` and the
stack configuration.

## 6. Orientation and agency

The stack exposes the local/global axis for downstream consumers:

    stack.tower_levels() -> list[int]     # tower level per layer
    stack.primes()       -> list[int]     # prime frequency per layer
    stack.branches()     -> list[str]     # 'even' or 'odd'
    stack.is_forbidden(layer_index) -> bool

`tower_level_for(layer_index, n_layers, local_first)` maps a layer index to a
tower level. With `local_first=True`, layer 0 is local (smallest prime, highest
resolvable frequency) and layer `n-1` is global. With `local_first=False`, the
mapping is reversed. A routing agent in RES-307 can read `tower_levels()` and
determine a layer's position on the axis from the level alone, without an
out-of-band index.

The tower's domain wall — the odd branch where `T(n) < 1` and the coupled
system `x^(x-1) = T(n)` has no real positive roots — is exposed as
`is_forbidden(layer_index)`. It is a structural property of the prime tower,
not a numerical threshold. In the mask-to-sheath reading, a stack layer on the
forbidden odd branch beyond the wall is in the sheath regime.

## 7. Non-claims

- No compression claim. The stack is a re-encoding. It does not reduce
  information content.
- No semantic claim. "Layer 0" and "layer K-1" are depth-ordered on a
  local/global axis, not semantically ordered.
- No learned structure. Masks are supplied by the caller. The stack does not
  search for optimal masks.
- No capacity guarantee. The stack's capacity is RES-313's problem.
- No claim that the sheath is a failure. The sheath is a regime. Whether it is
  desirable depends on the application. RES-315 is where that is decided.
- No claim that the mask influences the carrier. The mask is metadata. The
  carrier is positional.

## 8. Open questions

- **Optimal layer count.** Given `n` and `dim`, how many layers should the
  stack have before the coarsest layer saturates? This is a RES-313 input.
- **Layer weight schedule.** Is `1 / (layer_index + 1)` the right schedule, or
  should weights follow the capacity of each layer's mask?
- **Sheath as feature.** If the sheath regime is reachable, is it a failure
  mode or a feature? A membrane boundary might be useful for some modulation
  consumers. This is RES-315's decision.
